# Roadmap

Completed foundation:

- strict domain model and reliable real-fixture New Recruit import;
- event-driven generic battle engine with snapshots and undo/redo;
- IndexedDB army/battle persistence and resume flow;
- mobile-first guided dashboard, army tracker, objectives, and battle log.

Recommended next milestone — Cauldron FFA 3 ruleset:

- automatic rival rotation and round-end primary scoring;
- operational plans, starting-point thresholds, and casualty attribution;
- secondary deck/evaluators, per-round caps, and mission actions;
- ruleset-specific reminders and twists.

Later milestones:

- full PWA service worker, install assets, and offline-shell verification;
- table mode, results, post-game statistics, and broader rulesets.
